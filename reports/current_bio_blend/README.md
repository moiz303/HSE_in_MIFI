# Фиксированные смеси Bio-transfer и CheMeleon

Проверены ровно три заранее выбранных веса биологического кандидата:
.25,.5,.75. SI усредняется в исходных единицах. Повторного обучения,
подбора по test-концентрациям или изменения очереди Kaggle нет.

| Доля Bio-transfer | Общая OOF MSE | Zero MSE | Bulk MSE,0<SI≤1000 |
|---|---:|---:|---:|
| .25 | 5039294.17 | 3853.54 | 42464.94 |
| .50 | 5023845.70 | 3454.88 | 40517.46 |
| .75 | 5015503.08 | 3427.13 | 40468.31 |
| Чистый Bio-transfer | 5014266.30 | 3770.28 | 42317.51 |

Смесь .75 немного уступает чистому Bio-transfer по основной MSE, улучшая
zero/bulk. Это обмен между метриками, не доказательство улучшения Kaggle.
В очереди остаётся чистый Bio-transfer, чтобы проверить его отдельно.

OOF-покрытие и истинные development SI совпадают у родителей; SHA обеих
родительских таблиц и прогнозов сохранены в report.json. Оба родительских
инференса проверены в отдельных процессах, арифметика и CSV проверяются
повторным чтением с допуском1e-12. Все официальные Scores смесей неизвестны.
