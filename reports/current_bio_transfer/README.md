# Публичное предобучение → конкурсный SI

Завершены18 прежних molecule/scaffold folds и8 matched-контролей.
Отдельная сеть обучается только публичным IC50, EC50 и CC50:4430 измерений,
1711 структур. Цензура задаёт односторонние ограничения. В validation-fold
исключены совпадающие структуры, для scaffold — также каркасы.
Конкурсные концентрации не читаются.

Замороженные предсказания публичных log-концентраций и log-отношений добавлены
к Morgan/RDKit-признакам. CatBoost обучается log1p(SI); matched-контроли
получают те же исходные признаки/параметры без биологических выходов.
Параметры и риск-ограничения зафиксированы до результатов.

`kaggle_only` обозначает **SI-калибровку** на267 конкурсных строках.
Предобучение биологических признаков использует публичные измерения.
`public_plus_kaggle` добавляет80 публичных SI-пар в калибровку.
У `base_*` контролей биологические выходы отсутствуют.
