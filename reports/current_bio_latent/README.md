# Публичные внутренние признаки вместо одних выходов

Новый фактор —32 промежуточных признака сети, предобученной на публичных
IC50/EC50/CC50. Прежние3 выхода и log-отношения сохраняются. Для малого
и fingerprint-входа есть matched output-only контроль; chemical-вариант
также меняет исходное представление на train-only PCA64 и не является
сравнением одного фактора с fingerprint-контролем.

Полный dense CheMeleon-вход остановлен по вычислительной стоимости до
завершения первого разбиения; причина и исходный код сохранены в
runtime_adjustment.json/source_before_runtime_adjustment.py.txt.
Итоговые6 вариантов используют новый план. Публичные состояния кэшируются
по фактическим обучающим измерениям:9 молекулярных folds используют одну
сеть, потому что все конкурсные структуры исключены из public заранее.

Все18 folds завершены,6 артефактов воспроизведены отдельно.

Основной заранее заданный критерий не пройден: ALL MSE не улучшена.
На3 scaffold-повторах выигран только1. Интервал выигрыша ALL MSE
относительно BioFp:[−45582;27890] включает проигрыш и отсутствие эффекта.
Остальные latent-варианты тоже не улучшают ALL MSE, а у некоторых
test/OOF экспозиция возрастает в77–205раз. Это сигнал риска, не доказательство
конкретных скрытых целей. По zero/bulk отдельно кандидат не продвигается.
