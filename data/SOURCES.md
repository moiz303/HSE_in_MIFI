# Источники данных

Заполняет A по ходу выгрузки. Задача требует указать, откуда происходит
загрузка, поэтому этот файл сдаётся вместе с кодом и базой.

Для каждого источника: ссылка, фильтр или запрос, дата выгрузки, сколько
строк пришло, сколько осталось после валидации, лицензия.

## Цель отбора

- Вирус: vaccinia virus (вакцинный и модельный штамм, не variola virus).
- Штаммы: VACV, VV, WR, Copenhagen, Lister, IHD — фиксируем, какой именно.
- Тип измерения: ингибирование (IC50, EC50) и цитотоксичность (CC50, TC50, CD50).
- Пара IC50/CC50 для одной молекулы берётся из одной работы и, по возможности,
  из одной клеточной линии. SI, собранный из двух разных статей, — это
  отношение двух несвязанных чисел, а не индекс селективности.
- Концентрации приводятся к µM через `src.data.schema.to_micromolar`.
