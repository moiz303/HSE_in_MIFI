# Аудит прежних экспериментов

Числа прочитаны из старых отчётов до удаления; вычисления заново не запускались. Это результаты прежних данных/моделей, а не оценка XGBoost.

- `train_20261106_223210.log`: HGB two_head RMSE log10=0.809, direct=0.754. Преимущество новой двухголовой модели ещё нужно проверить.
- `train_20261107_015439.log`: HGB пропускался из-за чужого параметра `n_estimators`, рейтинг строился среди выживших вариантов. Новый код принимает явные параметры XGBoost и останавливается при ошибке.
- В опыте с цензурой первоначально меняли validation между вариантами. Это делает результаты несопоставимыми. Теперь разбиение фиксировано, экспорты сверяются с манифестом.
- Калибровка: лучший эффект −2.6%, t=0.89; критерий ужесточили после просмотра результатов. Это не подтверждение улучшения. Калибровки в новом пути нет.
- `experiment_floor.json`: прежний HGB MSE=19,818,407 против константы 22,866,168 в повторной CV; 57.2% ошибки приходилось на строки с условными SI-метками.
- Sentinel-смесь после исправления ослабленной базы не дала убедительного выигрыша; +0.5% среди 18 сравнений не подтверждает успех. Эти ветки удалены.
- Вывод «не выбрасывать SI-метки из SI-регрессии» нельзя переносить на обучение концентраций. Выдумывать IC50 для SI=10000 нельзя. Доступные точные концентрации сохраняются независимо для каждой головы; SI оценивается также на строках-метках.
- Метрика соревнования — MSE сырого SI, не RMSE логарифма. Отношение двух лог-регрессий не оптимизирует её напрямую и может уступить константе. Новый отчёт показывает обе шкалы и сравнение с train-only константой.
- Концентрации из разных анализов не всегда образуют согласованную пару; отношение медиан CC50/IC50 может отличаться от SI базы. Исходные измерения и DOI сохранены для переработки пар по протоколу.

Старые модели, submission, логи и таблицы экспериментов удалены из рабочего дерева; история остаётся в Git. Обучения XGBoost и новых результатов пока нет.
