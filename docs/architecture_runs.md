# Проверка четырёх архитектур

## Метрика и возможность точного совпадения

Формула соревнования — MSE сырого SI. Для идентичного численного результата
нужны те же истинные цели и те же public-ID. Kaggle предоставляет train_v2,
test и образец submission, но не официальные тестовые SI и public-маску.
Доступные концентрации дают 468 точных отношений из 597; это другой эталон.
Улучшить формулу так, чтобы она восстановила скрытые данные, нельзя.

`python -m src.score_audit` фиксирует эту границу и сравнивает известные
заявки по проверенному SHA256. Для нового файла официальный Score остаётся
неизвестным до отправки. Для известного файла можно точно показать ранее
полученный Score; это lookup, не локальное вычисление. Множитель или регрессия
по нескольким leaderboard-числам не применяются.

Если организаторы предоставят цели и public-маску, функция
`official_reference_mse` принимает `index,target,is_public` и вычисляет MSE
на точных public-строках после строгого сопоставления ID. Эти данные используются
только для оценки, не для обучения или инференса.

## Изолированное окружение

Основное окружение XGBoost сохраняется. На Windows:

```powershell
uv venv --python 3.12 ../env_arch
uv pip install --python ../env_arch/Scripts/python.exe torch==2.6.0 --index-url https://download.pytorch.org/whl/cpu
uv pip install --python ../env_arch/Scripts/python.exe -r requirements-architectures.txt
../env_arch/Scripts/python.exe -u -m src.architecture_workflow
../env_arch/Scripts/python.exe -m src.architecture_results
```

Chemprop 2.2.1 выбран из-за отсутствия совместимых Windows cuik-wheels для
2.3.1. Uni-Mol требует numpy<2.3, поэтому установлено отдельное окружение с
numpy 2.2.6 и pandas 2.2.3. Полный список версий: `reports/architectures/environment.txt`.
Для Mac используйте Python 3.12 и `python -m pip install -r requirements-architectures.txt`.
CPU-launcher совместим с Mac; CUDA не требуется и совместимость MPS не заявляется.

## Протокол

`configs/architectures.json`: последовательность CheMeleon → совместный GP →
Uni-Mol → доменные головы. Те же 1007 train+validation структур, 3 fold ×
3 повторения в molecule/scaffold протоколах, holdout исключён. Каждый scaler
обучается только внутри fit-части fold. Вход тестового инференса — только ID/SMILES.

Первичный критерий выбора внутренних вариантов — средний относительный OOF-MSE
исходных обучающих SI с `target_is_label=false` по двум протоколам. Общий SI-MSE
и условные метки оцениваются отдельно. Это более явное разделение целей,
а не обещание совпадения с неизвестной public-подвыборкой.

- **CheMeleon:** замороженный авторский D-MPNN, кандидаты Ridge alpha=10/100
  и общая MLP с двумя маскированными целями. Контроль: тот же случайный энкодер
  и MLP; контроль не выбирается как результат предобученного метода.
- **GP:** полная совместная ковариация Tanimoto, корреляция задач и отдельный шум
  голов; гиперпараметры оцениваются по likelihood только на fit. Сравниваются
  медиана и среднее SI совместного логнормального распределения. Ковариация
  входит в дисперсию разности. Экспонента ограничена [-80,80] для численной
  конечности, не для подгонки к тестовому Score.
- **Uni-Mol:** замороженный авторский 3D-энкодер, один конформер с seed=42,
  те же Ridge/MLP-головы. Внутренний 2D-fallback — политика библиотеки; внешние
  исключения дают нулевой embedding с флагом и сохраняются в аудите. При
  систематических сбоях или >5% исключений метод останавливается.
- **Доменные головы:** тот же CheMeleon, обучаемая общая MLP-часть и отдельные
  public/Kaggle выходы для IC50/CC50. На инференсе всегда Kaggle-ветвь. Pooled
  и Kaggle-only — отдельные контроли; основной вариант — доменная модель.

MLP: 160 фиксированных эпох, batch=128, AdamW lr=0.001, weight_decay=0.01,
hidden=64, dropout=0.15. Недостающие/цензурированные концентрации маскируются
независимо. Полное дообучение больших энкодеров в этом CPU-опыте не выполняется.
Замороженные представления вычисляются без целевых данных; их кэш не является
обучением на тестовых целях.

## Файлы и условная отправка

Авторские веса в `artifacts/pretrained/` и embeddings в `data/architecture_cache/`
игнорируются Git. URL, ревизии и контрольные суммы сохраняются в отчётах.
CheMeleon сверяется с MD5 издателя Zenodo, Uni-Mol — с LFS SHA256 и закреплённой
ревизией. Загрузка идёт напрямую по проверяемому TLS: локальный environment
proxy давал таймауты. Системные proxy-настройки не меняются.

Модели: `artifacts/architectures/<метод>.joblib`; OOF, разбиения, конфигурации,
прогнозы и аудит: `reports/architectures/<метод>/`. Итоговая таблица:
`reports/architectures/comparison.md/.csv/.json`. Для повторного инференса:

```bash
python -m src.architecture_workflow --predict-artifact artifacts/architectures/chemeleon.joblib --out reports/chemeleon_prediction.csv
```

Все четыре прогноза сохраняются до чтения тестовых концентраций. По новому
явному указанию пользователя разрешена одна заявка лучшего нового метода,
если его локальный MSE на общей маске строго ниже **1 900 000**. Официальный
Score после неё записывается отдельно; прогнозировать его идентичным локальному
оснований нет. Команды обучения и сравнения сами не вызывают Kaggle API.
