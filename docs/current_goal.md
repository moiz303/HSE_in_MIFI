# Поиск top10 или Score ниже 800000

Пользователь заменил первоначальную цель top5 на top10 **или** Score<800000
и разрешил проверять лучшие гипотезы на Kaggle. На старте оставалось четыре
попытки команды; счётчик проверен по живой истории заявок (16/20 сегодня).
Истина об отправках: reports/current/kaggle_goal_submissions.json.

Меньше лучше. Все OOF — на тех же 267 исходных строках train_v2,
включая нули, 18 molecule/scaffold folds. Никаких test endpoints при выборе.
Результаты исследовательские: широкое сравнение повторно использует OOF,
независимый holdout остаётся закрыт. Формула MSE совпадает с Kaggle, эталон
и набор оцениваемых строк отличаются; тождественности чисел не заявляем.

Второй блок не обошёл исходный SI-кандидат. Для отдельных фолдов Tweedie был
лучше, но суммарно победил quantile-boosting, который также уступил CheMeleon.
У TabPFN математическое ожидание SI приближено 20 средними квантилями распределения
log1p(SI); это усечённая численная аппроксимация, не точное ожидание хвостов.
Использован авторский [Prior Labs TabPFN-v2](https://huggingface.co/Prior-Labs/TabPFN-v2-reg)
с атрибуцией; checkpoint SHA256 сохранён в отчёте, окружение отделено.

## Проверки

Сериализация одного kernel-кандидата различалась на 4.55e-13 из-за float64
вычислений. Исправлена только проверка равенства на rtol/atol=1e-12;
обучающий код и OOF не менялись. Исходный файл и явный аудит смены
проверки сохранены в reports/current_search/verification_fix.json.

Cap .99 вычисляется только по SI train-части каждого fold. Все его OOF
прогнозы равны исходным. На финальном test ограничены три прогноза;
официальный Score стал немного хуже. Этот результат не оправдывает
автоматическое продвижение cap-модели.

Цель пока не достигнута. Auxiliary-блок завершён: 4430 отдельных измерений,
1711 молекул, раздельные IC50/EC50/CC50 задачи; цензура задаёт границы.
Лучший контроль — дополнительные эпохи без auxiliary; существенного выигрыша
от вспомогательных задач нет. Конкурсные концентрации нигде не использованы.

После аудита проверены лучший по raw OOF mixed GP и умеренный Kaggle-only
hurdle с лучшей bulk MSE в5/6protocol×repeat групп. Оба проиграли CheMeleon
на Kaggle; четыре исходные попытки исчерпаны. Не используем Score для
восстановления скрытых целей или подгонки локальных меток.

## Правило преемственности исследований

Перед запуском прочитать research_registry.json, all_models.csv и
docs/previous_experiments.md; записать изменённый фактор и сравнимый контроль.
Повтор неудачного блока без нового фактора не считается новой гипотезой.
Проверка воспроизводимости и повторное использование кэша допустимы, но
не увеличивают число независимых подтверждений. Ни локальные страты, ни
подбор по многим OOF не гарантируют улучшения публичного Score.
