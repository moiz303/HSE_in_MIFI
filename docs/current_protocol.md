# Текущий протокол соревнования

Проверено 7 ноября 2026 через авторизованный Kaggle API: страницы description,
evaluation, data и rules, метаданные и список файлов соревнования
[Molecular Activity Prediction](https://www.kaggle.com/competitions/molecular-activity-prediction-hack/overview).
Проверка касается технических требований к решению; окончательное решение о допуске принимает организатор.

## Разрешённые данные

[Описание данных](https://www.kaggle.com/competitions/molecular-activity-prediction-hack/data)
запрещает конкурсные CC50_uM и IC50_uM_VACV для построения моделей и предсказания.
Команда подтвердила строгую трактовку без исключения для обучающих целей.
Новый загрузчик читает только SMILES и SI VACV; инференс — index и SMILES.
Это проверяется контрфактическим тестом изменения запрещённых столбцов.
Прежние концентрационные головы оставлены как история и исключены из текущего протокола.

Актуальный train_v2.csv содержит 320 строк и 83 нуля: 81 прежняя цель 10000
заменена организаторами на 0. SHA256 закреплён в configs/current.json.
Для сопоставимости сохранены прежние роли структур: 267 development-строк,
66 нулевых целей. Остальные 53 конкурсные строки не использованы; две из них
были исключены старой сборкой и не являются новым holdout. Первоначальный
резерв структур и его каркасы защищены. Старые значения SI и концентраций
из data/processed не попадают в новую обучающую таблицу.

## Публичные источники

Условие требует скрипт сбора публичных данных и собранную таблицу с молекулами,
концентрациями, SI и DOI при наличии. Реализация: src/current/collect.py;
использованный снимок и журнал исключений: data/current/.
Источник — [ChEMBL API](https://www.ebi.ac.uk/chembl/api/data/),
VACV ORGANISM-цели CHEMBL613493 и CHEMBL613168; тип целей повторно проверен через API.
Существующий снимок измерений очищен повторно; полный новый сетевой сбор
в этом эксперименте не запускался. Скрипт создаёт отдельный снимок и не подменяет данные обучения.

Точные положительные IC50/CC50 сопоставлены по структуре, документу и известной
клеточной линии. Цензурированные значения, EC50/TC50/GI50 и неизвестные линии
исключены. Получено 109 пар / 87 структур, DOI заполнен у всех. После исключения
конкурсных структур и резервных каркасов доступны 80 пар / 63 структуры.
Совпадение статьи и линии не гарантирует одинаковые время и протокол измерения;
это остаётся ограничением качества публичных SI. Конкурсные цели не усредняются с публичными.

Фиксированный [авторский CheMeleon](https://zenodo.org/records/15460715)
используется как энкодер SMILES с проверкой контрольной суммы; концентрации
конкурса для него и новых SI-голов не используются.

## Сравнение и выбор

Обучены семь методов в двух режимах на одинаковых 18 разбиениях:
3 folds × 3 repeats × molecule/scaffold. Метрика выбора — среднее MSE по двум
протоколам на всех исходных development-строках, включая нули. Публичные
аналоги исключаются из соответствующих validation-групп. Скейлеры обучаются
внутри fold; параметры нормирования цели берутся из конкурсной train-части.

После первого блока с raw SI добавлены log1p-контроли из-за нестабильности
на обучающих OOF и тяжёлого хвоста. Результаты первого блока сохранены отдельно.
Для каждого блока выбор фиксировался до его endpoint-диагностики. Это
исследовательское сравнение с повторным использованием OOF, а не независимое подтверждение.

Лучший OOF: CheMeleon domain log1p + public, MSE 5 061 848,48 против
нулевого прогноза 5 153 198,43. Выигрыш 1,77%; кластерный bootstrap-интервал
выигрыша [-3 899; 255 115] включает отсутствие улучшения. Добавление public
для этого метода улучшает OOF лишь на 0,29%, также без устойчивого подтверждения.

Отдельная диагностика после инференса использует доступные отношения CC50/IC50
только для 468 из 597 test-строк. Она не является истинной скрытой целью SI,
не знает public/private-маску и не равна официальному Kaggle MSE.
Лучший диагностический результат нового набора: CatBoost log1p + public,
1 968 835,32. Он не заменяет OOF-выбор. Исходный CatBoost из testing_main
воспроизводится: 4 187 780,79 после ограничения отрицательных прогнозов нулём.
