## Следующие варианты для выбора

1. **Расширить независимые точные IC50 и CC50.** Сейчас финальная IC50-голова
   обучается всего на 465 значениях. Сборщик публичной базы требует пару в одной
   статье, хотя двум независимым головам это не обязательно. Можно сохранить
   дополнительные непарные точные измерения, проверяя endpoint, вирус и условия.
   При OOF исключать из публичного train все молекулы/каркасы проверяемой части;
   holdout по-прежнему исключён. Объём пригодных новых измерений пока неизвестен.
2. **Добавить прогноз по близким обучающим аналогам.** Morgan/Tanimoto-соседи
   дают отдельные оценки концентраций; ограниченная смесь с XGBoost выбирается
   только на обучающих OOF-прогнозах. Проверить activity cliffs и устойчивость
   к отсутствию близкого аналога. Для запроса нужны только SMILES; тестовые
   CC50/IC50 не являются базой соседей и не участвуют в настройке смеси.
3. **Проверить MSE-ориентированное обучение для высоких SI.** Фиксированная,
   ограниченная по величине надбавка к train-весам для достоверных пар с высоким
   измеренным SI, особенно для IC50-головы. Условные метки SI=10000 не считать
   измеренными парами. Сравнить потери на всех строках и обычных SI, чтобы
   не повторить завышение прогнозов гибридом. Это рискованный эксперимент,
   параметры нельзя выбирать по тестовым диагностическим концентрациям.

На локально диагностируемых 468 строках варианта 3 пять крупнейших ошибок дают
83.1% всей квадратичной ошибки, десять — 91.2%. 28 строк с SI>=1000 дают 99.3%.
Это направление для исследования, не основание вручную исправлять отдельные
тестовые прогнозы или гарантировать результат на скрытых строках.

Все три подхода пока предложения, не реализованные улучшения. Рекомендуемое
первое направление — расширение независимых измерений; быстрый модельный контроль —
прогноз по близким аналогам. Следующие заявки требуют нового указания пользователя.
