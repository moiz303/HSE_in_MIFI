## Следующие варианты для выбора

1. **Расширить независимые точные IC50 и CC50.** Сейчас финальная IC50-голова
   обучается всего на 465 значениях. Сборщик публичной базы требует пару в одной
   статье, хотя двум независимым головам это не обязательно. Можно сохранить
   дополнительные непарные точные измерения, проверяя endpoint, вирус и условия.
   При OOF исключать из публичного train все молекулы/каркасы проверяемой части;
   holdout по-прежнему исключён. Объём пригодных новых измерений пока неизвестен.
2. **Добавить прогноз по близким обучающим аналогам.** Morgan/Tanimoto-соседи
   дают отдельные оценки концентраций; ограниченная смесь с XGBoost выбирается
   только на обучающих OOF-прогнозах. Проверить activity cliffs и устойчивость
   к отсутствию близкого аналога. Для запроса нужны только SMILES; тестовые
   CC50/IC50 не являются базой соседей и не участвуют в настройке смеси.
3. **Проверить MSE-ориентированное обучение для высоких SI.** Фиксированная,
   ограниченная по величине надбавка к train-весам для достоверных пар с высоким
   измеренным SI, особенно для IC50-головы. Условные метки SI=10000 не считать
   измеренными парами. Сравнить потери на всех строках и обычных SI, чтобы
   не повторить завышение прогнозов гибридом. Это рискованный эксперимент,
   параметры нельзя выбирать по тестовым диагностическим концентрациям.

На локально диагностируемых 468 строках варианта 3 пять крупнейших ошибок дают
83.1% всей квадратичной ошибки, десять — 91.2%. 28 строк с SI>=1000 дают 99.3%.
Это направление для исследования, не основание вручную исправлять отдельные
тестовые прогнозы или гарантировать результат на скрытых строках.

Этот список был составлен до экспериментов. Проверка аналогов выбрала alpha=0:
выигрыша для продвижения не хватило. Проверка усиления обучения приведена ниже.
Расширение независимых измерений остаётся непроверенным направлением.
Следующие заявки требуют нового указания пользователя.

## Третий подход: усиление обучения, Windows 07.11.2026

Команда: `python -u train_model.py --config configs/xgb_tail.json --predict data/raw/kaggle/test.csv --out reports/submission_xgb_tail.csv`.
Реальные данные, 1007 структур train+validation; holdout исключён.
Сравнение на исходных 267 обучающих строках Kaggle (повторы наблюдений сохранены):
molecule/scaffold, 3 fold × 3 повторения. 72 пары моделей с фиксированными
параметрами по 400 деревьев на голову. Полный запуск занял 178.2 секунды.

Множитель веса `clip(sqrt((CC50/IC50)/100), 1, cap)` вычислялся исключительно
внутри fit-части каждого fold, только для точных пар с явным флагом измеренной
цели. Условные SI=10000, неизвестные флаги, цензура и неполные пары не усиливались.
Исходные веса надёжности и набор признаков оставлены прежними.

| Профиль | Molecule OOF MSE | Scaffold OOF MSE | Scaffold MSE, SI<=100 |
|---|---:|---:|---:|
| Обычные веса | 29 666 852.33 | 29 681 667.99 | 14 373.00 |
| IC50, cap=2 | 29 631 920.75 | 29 681 477.12 | 50 017.27 |
| IC50, cap=4 | 29 606 141.02 | 29 725 632.27 | 151 792.38 |

Максимальный выигрыш molecule-MSE — только 0.205% вместо требуемых 2%.
При этом ошибка на обычных SI существенно выросла у всех профилей:
на scaffold-протоколе в 3.48/10.56/4.15 раза соответственно.
IC50 cap=4 также ухудшил MSE измеренных scaffold-целей с 6 730 053 до 6 806 674.
Небольшой выигрыш на случайном разбиении не компенсирует эти последствия.
Это результат конкретных ограниченных весов, не доказательство бесполезности
любого способа обучения на высоких SI.

**Выбран обычный weighted**, финально обучены 465 IC50 и 682 CC50.

## Шесть независимых гипотез: завершённая проверка

Порядок: независимые измерения → признаки → цензура → прямой SI → согласованность
пар → параметры голов. Все изменения проверены отдельно от одного Windows
weighted; внутренние варианты выбраны по molecule/scaffold OOF до отдельной
диагностики тестовых концентраций. 3 fold × 3 повторения, те же 267 исходных
обучающих строк и 1007 структур train+validation, holdout исключён.

| Гипотеза | Локальный Score, MSE | Изменение ошибки к базе |
|---|---:|---:|
| Исходный Windows weighted | 1 932 650.98 | — |
| Расширение независимых измерений | 5 557 739.86 | хуже на 187.57% |

Score рассчитан одной постинференсной проверкой на одинаковых 468/597 доступных
точных отношениях CC50/IC50. Это диагностический срез, не официальный Kaggle Score.
Новые условные метки для оставшихся 129 строк не создавались. Ни одна гипотеза
не прошла все OOF-предохранители; основная модель не заменена.

Расширение добавило 222 точных IC50/EC50 и 313 CC50/TC50 по новым структурам:
финальные головы получили 687 и 995 целей соответственно. Отсутствующие партнёры
не восстанавливались. При аудите первоначального широкого сбора обнаружены тесты
отдельных белков; они исключены до итогового сравнения. Новый сбор ограничен
двумя ChEMBL-целями целого вируса, сохраняет документы, анализы, единицы и отказы.
Дополнительные структуры holdout-каркасов и проверяемых fold исключались.
Предварительный ошибочный сбор отмечен в `independent_broad_source_audit.json`
как недействительный и не участвовал в диагностике или выборе заявки.

Для признаков проверены counts/radius3/Feature Morgan; AFT сравнивался на точных
и точных+цензурированных целях; прямой SI — в смесях 0.1/0.25/0.5/1.
В параметрах проверены девять комбинаций трёх профилей. Выбраны IC50 depth=4,
800 деревьев, min_child_weight=10, reg_lambda=10; CC50 оставлен прежним.
Его molecule/scaffold OOF MSE: 29 585 997.70 / 29 699 401.69; рост ошибки низких
SI не прошёл предохранитель, поэтому локальные 2.01% не считаются подтверждением
улучшения на скрытом тесте.
