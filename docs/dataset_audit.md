## Качество измерений

- В исходном Kaggle 81/320 строка не содержит IC50, SI там равен 10000. Это условная метка, не измеренное отношение. Нельзя восстанавливать из неё IC50.
- В итоговой базе 689 строк со знаком цензуры хотя бы у одного измерения; 205 имеют флаг артефакта SI=1. Пороги не являются точными концентрациями.
- Точные положительные цели после отдельных масок: IC50 — 563, CC50 — 798; обе одновременно — 416 структур. В train доступны 365/565 целей, в validation — 100/117.
- В 1023 парах ChEMBL правила подбора токсичности: та же линия — 596; та же статья без подтверждения линии — 381; рукав VACV и та же линия — 28; рукав VACV, другая линия — 18. Это неоднородная по качеству разметка.
- В публичных данных 837 EC50 и 186 IC50 записаны в одну колонку IC50. Исходный тип сохраняется в `assay_type` сырых пар, но при агрегации берётся только первое значение.
- Загрузчик допускает CC50/TC50/CD50/GI50 для токсичности, однако исходный тип токсикологического endpoint в `chembl.csv` не сохраняется. Проверить его эквивалентность CC50 по этому CSV невозможно.
- DOI заполнен у всех 1023 публичных пар. 253 итоговые структуры только из Kaggle не имеют DOI; это не потеря ссылок ChEMBL.

## Обнаруженные проблемы

1. **Смешивание разметки разных источников.** На 57 общих структурах показатели Kaggle и ChEMBL агрегируются вместе. По сравнению с лог-медианой только Kaggle IC50 меняется более чем на 25% у 8 структур, CC50 у 14, SI у 15; SI более чем вдвое меняется у 6. Поэтому выборка с `source` содержащим `kaggle_train` уже не является проверкой исходной цели Kaggle.
2. **Независимые медианы нарушают согласованность пары.** У 4 итоговых структур SI отличается от CC50/IC50 более чем на 0.25 log10 (примерно в 1.78 раза). В сырых строках с полными концентрациями таких нарушений нет. Даже без такого нарушения измерения из разных анализов нельзя считать одной согласованной экспериментальной парой.
3. **Потеря контекста при агрегации.** Клеточная линия, тип анализа и правило подбора токсичности берутся из первой строки группы, хотя концентрации агрегируются по всем. После объединения источников контекст может не описывать итоговую концентрацию.
4. **Обход валидации при отсутствующем флаге.** `bool(NaN)` давал True и отправлял строки ChEMBL в упрощённую проверку SI-меток. Исправлено; добавлены тесты на NaN, pd.NA, None и строковое False. Пересборка датасета в рамках аудита не выполнялась.

## Вывод и следующий шаг

Это пригодный исходный сборник для дальнейшей очистки, но не готовый эталонный датасет для доказательства качества двух моделей. Текущий запуск XGBoost технически возможен; его метрики предварительные.

Перед модельными выводами нужна отдельная версия сборки: сохранить исходные цели Kaggle для validation; не усреднять их с публичными; группировать публичные измерения по совместимым условиям/endpoint; явно хранить тип токсичности; точные измерения отделять от границ. Общие структуры источников должны оставаться в одной части фиксированного scaffold-разбиения. Концентрационные модели могут использовать непарные точные цели, а проверка SI должна отличать реальные пары от условных меток.

Существующие источники, датасет и разбиение в ходе аудита не изменены, чтобы не подменить условия предстоящего сравнения.
