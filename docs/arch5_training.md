# Architecture 5 training

Reproduce: `python -m src.arch5_compare --config configs/xgb_arch5.json` in scientific runtime including XGBoost. 3-fold scaffold development CV x3 seeds (20261106–20261108), nested scaffold public predictions for residual fitting. Original Kaggle reference is filtered to development structures; holdout/test targets excluded. Final public/residual models saved in `artifacts/arch5_source_hierarchy.joblib` with inference formula and config.

Final numerically stable StandardScaler + Ridge original-target SI MSE: 31,529,999.32 vs Kaggle-only control 29,619,524.36. Weighted XGBoost from architecture 1 on verified identical original rows/folds/repeats: 29,682,392.14. No improvement; no promotion. An earlier unscaled Ridge ablation gave 29,579,318.71 but emitted ill-conditioned-system warnings; its report remains in commit 1a64e1b. Scaling is fitted inside each valid training target mask, and serialized with the residual head. These are OOF scores, not Kaggle public scores. Baseline default unchanged.

Real-data runs caught two runner issues: filtering the full Kaggle reference to development, and retaining unrelated public scaffolds inside nested OOF (only held scaffolds should be excluded). The latter is covered by a new regression test. Six architecture-specific tests passed, including a toy benchmark integration check for unseen held structures and exactly-once original rows; saved artifact reload/inference passed. Huge apparent loss in an intermediate buggy run was corrected before final results.
