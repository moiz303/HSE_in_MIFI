# Исторические команды

`train_model_v1.py` и `run_mac_v1.sh` сохранены для воспроизведения прежних
экспериментов. Они обучали концентрационные головы и использовали старый
processed-датасет. Это не текущий протокол соревнования.

Актуальный запуск из корня: `python train_model.py --help`.
Текущий пакет: `src/current/`, конфигурация: `configs/current.json`.
Он читает из Kaggle только SMILES и SI VACV и сохраняет нулевые цели train_v2.

Старые модули `src/models/`, конфигурации и артефакты сохранены ради совместимости
с ранее обученными моделями и проверки исторических результатов.

Полное исходное дерево старого эксперимента воспроизводится в отдельном
`git worktree` на коммите из его отчёта. Архивные shell-команды сохраняют
исторические пути. Для Python-архива из корня используйте
`python -m legacy.train_model_v1`, а не новый `train_model.py`.
